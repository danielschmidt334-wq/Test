# English Quick Check — Mobile Quiz

Mobiler Englisch-Test (Grammatik & Wortschatz, 10 Fragen) für Schülerinnen und Schüler — optimiert für Smartphones.

## Lokal öffnen

```bash
cd /workspace
python3 -m http.server 8080 --bind 0.0.0.0
```

Dann im Browser: `http://localhost:8080` (am Handy im gleichen WLAN: `http://<deine-IP>:8080`).

Die Dateien kannst du auch auf **GitHub Pages**, **Netlify** oder einen Schul-Webspace hochladen — es sind nur statische HTML/CSS/JS-Dateien.

## Anpassen

- Fragen bearbeiten: `questions.js`
- Farben & Layout: `styles.css`
- Titel und Texte: `index.html`
